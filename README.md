Entry for the make.fun competition
`u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b`.

`main.ts` writes a single one-line pickup line a robot could use to `/output/entry.txt`. The line is validated
before it is written: 1 to 200 characters, a single line, not only white
space.

The entry line:

> Are you a firmware update? Because every time I see you, I reboot and suddenly everything works better.
